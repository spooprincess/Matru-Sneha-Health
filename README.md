# Matru Sneh Health 🤱❤️

**Matru Sneh Health** is a modern, comprehensive Android application designed to support expectant mothers throughout their pregnancy journey. The app provides essential tools for tracking fetal health, managing medical appointments, and ensuring proper nutrition.

## 🌟 Key Features

- **🦶 Kick Counter**: Track and log fetal movements (kicks) to monitor your baby's activity levels.
- **📅 Checkup Reminders**: Never miss a doctor's appointment with automated reminders and a dedicated checkup schedule.
- **🍎 Nutrition Tracker**: Guidance and tracking for maintaining a healthy diet during pregnancy.
- **🏥 Health Monitoring**: Log and monitor vital health statistics to stay informed about your well-being.
- **🌐 Multilingual Support**: Accessible in multiple languages to support diverse users.
- **🔔 Smart Notifications**: Background workers ensure you stay updated on important tasks and reminders.

## 🛠️ Tech Stack

- **Language**: [Kotlin](https://kotlinlang.org/)
- **UI Framework**: [Jetpack Compose](https://developer.android.com/jetpack/compose) (Modern Android UI)
- **Database**: [Room Persistence Library](https://developer.android.com/training/data-storage/room)
- **Background Tasks**: [WorkManager](https://developer.android.com/topic/libraries/architecture/workmanager)
- **Design**: Material Design 3 (M3)

## 🚀 Getting Started

### Prerequisites
- Android Studio Ladybug (or newer)
- JDK 17+
- Android Device/Emulator (API 24+)

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/spooprincess/Matru-Sneha-Health.git
   ```
2. Open the project in Android Studio.
3. Wait for Gradle sync to complete.
4. Build and run the app on your device.
